
## 📌 4.10: "Предпочитайте вложенный статический класс вложенному внутреннему классу"

### 📘 Про що це?
🔑 Головна ідея:
>Якщо вкладений клас не потребує доступу до полів і методів зовнішнього класу — зроби його статичним (static).

### 🛠 Просте пояснення:
В Java є два типи вкладених класів:
- Внутрішній клас (non-static inner class):
  - Має неявне посилання на об'єкт зовнішнього класу.
- Статичний вкладений клас (static nested class):
  - Не має посилання на зовнішній клас.

❗️ Чому важливо:
- Внутрішній клас зберігає посилання на свій "зовнішній" об'єкт → пам'ять витрачається більше, і є ризик витоків пам'яті (Memory Leak).
- Статичний клас легший, швидший і безпечніший.
- Якщо вкладений клас не потребує доступу до об'єкта, немає сенсу тягнути зайву залежність.

❌ Погано (внутрішній клас, який не використовує зовнішній об'єкт):
```java
public class Outer {
    private String name;

    public class Inner {
        public void print() {
            System.out.println("Hello");
        }
    }
}
```
- Тут Inner має посилання на Outer, хоча не використовує його взагалі.

✅ Добре (статичний вкладений клас):
```java
public class Outer {
    private String name;

    public static class Inner {
        public void print() {
            System.out.println("Hello");
        }
    }
}
```
- Тепер Inner живе сам по собі: ніякої зайвої прив'язки до Outer.



### 📋 Коли який тип класу використовувати?
| *Потребує доступу до полів/методів зовнішнього класу?* | *Використовуй*                     |
|--------------------------------------------------------|------------------------------------|
| Так                                                    | Внутрішній (звичайний) клас        |
| Ні                                                     | Статичний вкладений клас (static)  |

### 🧠 Висновок:
| *Якщо вкладений клас*                      | *Використовуй*             |
|--------------------------------------------|----------------------------|
| Не потребує доступу до зовнішнього об'єкта | static вкладений клас      |
| Потребує доступу                           | Звичайний внутрішній клас  |




## 4.10 Предпочитайте вложенный статический класс вложенному внутреннему классу (Item 24)

Виды классов внутри других классов(nested class) в Java:

- Вложенный статический класс(static member class)
- Вложенный внутренний класс(nonstatic member class)
- Анонимный класс(anonymous class)
- Локальный класс(local class)

Алгоритм подбора вида класса:

* Если класс внутри другого класса должен быть виден за пределами метода или он слишком длинный, для размещения в
  границах метода, используйте вложенный класс(static или nonstatic).
    * Если каждому экземпляру вложенного необходима ссылка на включающий его экземпляр, делайте его внутренним классом(
      nonstatic member class)
    * В остальных случаях статистический(static member class)
* Если класс находится внутри метода и нужно создавать экземпляр в одном месте программы и имеется тип для этого
  класса - анонимный класс(anonymous class)
* В остальных случаях локальный(local class)
