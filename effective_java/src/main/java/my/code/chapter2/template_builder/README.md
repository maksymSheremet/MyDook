# Шаблон "Будівельник" (Builder Pattern)

Якщо у класу багато параметрів у конструкторі, код стає важким для розуміння і підтримки. Щоб зробити його зручнішим, використовується шаблон "Будівельник" (Builder Pattern).

## 🚨 Проблема

Уяви, що ти хочеш створити об’єкт Car, який має багато характеристик:

- марка
- модель
- двигун
- кількість дверей
- тип коробки передач
- колір
- кондиціонер (так/ні)
- навігація (так/ні)

Якщо всі ці параметри будуть у конструкторі, код буде жахливим:  
Car car = new Car("Toyota", "Camry", "2.5L", 4, "Автомат", "Чорний", true, true);  
Ти дивишся на цей код і думаєш: "А що означають ці true?!"

## 🏗 Рішення: шаблон "Будівельник"

Будівельник дозволяє покроково створювати об’єкт, додаючи тільки потрібні параметри:  
```java
    Car car = new Car.Builder("Toyota", "Camry")  
        .engine("2.5L")  
        .doors(4)  
        .transmission("Автомат")  
        .color("Чорний")  
        .airConditioning(true)  
        .navigation(true)  
        .build();
```    
Тепер усе зрозуміло, і ми не заплутуємося у великій кількості параметрів.

## 🔥 Головне про Builder Pattern

- ✅ Розбиває створення об'єкта на зручні кроки
- ✅ Код стає зрозумілішим
- ✅ Можна створювати об’єкт з різними наборами параметрів

## 2.2 При большом количестве параметров конструктора подумайте о проектном шаблоне Строитель (Item 2)

- Если конструктор или статические фабрики имеет большое количество параметров(4+), то лучше рассмотреть шаблон
  Строитель при создании объекта
- Код клиента проще для чтения и записи
- Безопаснее чем шаблон `JavaBeans` и может быть неизменяемым
